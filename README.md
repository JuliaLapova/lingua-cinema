# Lingua Cinema

**Смотрите фильмы на английском с английскими и русскими субтитрами рядом.**

Lingua Cinema — настольный видеоплеер для Linux, который помогает разбирать английскую речь по фильмам. Откройте локальное видео, подключите субтитры и следите за диалогами в боковой панели: оригинал и перевод отображаются друг под другом.

![Интерфейс Lingua Cinema: видеоплеер и боковая панель английских и русских субтитров](docs/images/lingua-cinema.png)

*Окно приложения до открытия фильма и загрузки субтитров.*

## Возможности

- Воспроизведение локальных видеофайлов, включая MKV, MP4, AVI и WebM, при наличии соответствующих кодеков.
- Английские и русские субтитры в одной боковой панели.
- Подсветка текущей реплики и автоматическая прокрутка диалогов.
- Переход к фрагменту фильма нажатием на реплику.
- Повтор текущей реплики и перемотка на 5 секунд.
- Выбор скорости воспроизведения, громкости и звуковой дорожки.
- Ручная корректировка времени показа субтитров.
- Автоматическая загрузка подходящих субтитров из фильма или соседних файлов.
- Сохранение позиции просмотра, выбранных файлов субтитров и временного сдвига.

Приложение работает локально: не загружает видео в интернет и не изменяет исходный фильм.

## Установка и запуск

### 1. Установите зависимости

Для Ubuntu / Debian и совместимых дистрибутивов:

```bash
sudo apt update
sudo apt install python3 python3-gi gir1.2-gtk-3.0 gir1.2-gstreamer-1.0 \
  gstreamer1.0-gtk3 gstreamer1.0-plugins-good gstreamer1.0-plugins-bad \
  gstreamer1.0-plugins-ugly gstreamer1.0-libav ffmpeg
```

Нужна графическая сессия Linux. В других дистрибутивах установите аналогичные пакеты Python 3, PyGObject, GTK 3, GStreamer с модулем `gtksink`, FFmpeg и ffprobe.

### 2. Скачайте проект

На странице репозитория выберите **Code → Download ZIP** и распакуйте архив либо склонируйте репозиторий через Git.

### 3. Запустите приложение

Откройте терминал в папке проекта:

```bash
sh start.sh
```

Можно сразу передать путь к фильму:

```bash
sh start.sh "/путь/к/фильму.mkv"
```

## Как смотреть фильм

1. Нажмите **«Открыть фильм»** и выберите видео.
2. Выберите английскую звуковую дорожку в списке под плеером, если в фильме несколько языков. Дорожка с меткой `en` или `eng` выбирается автоматически.
3. Если субтитры не загрузились автоматически, нажмите **«EN · Загрузить»** и **«RU · Загрузить»**, чтобы выбрать файлы на каждом языке.
4. Нажмите **▶** или пробел для начала просмотра.
5. Нажмите на реплику справа, чтобы перейти к ней, или **«↺ Реплика»**, чтобы повторить текущую фразу.

Чтобы читать диалоги независимо от видео, отключите **«Следовать за текущей репликой»**.

### Подключение субтитров

Внешние файлы: **SRT** и **VTT**. Из фильма автоматически извлекаются поддерживаемые текстовые дорожки с языковыми метками `en` / `eng` и `ru` / `rus`, включая ASS/SSA с преобразованием в простой текст.

Для автоматического поиска рядом с фильмом используйте одинаковое основное имя:

```text
Movies/
├── My Film.mkv
├── My Film.en.srt
└── My Film.ru.srt
```

Также подходят языковые суффиксы `.eng`, `.rus` и расширение `.vtt`. При других именах подключите файлы вручную кнопками **EN** и **RU**.

### Управление

| Действие | Кнопка или клавиша |
| --- | --- |
| Воспроизведение / пауза | ▶ / пробел |
| Назад на 5 секунд | −5 с / ← |
| Вперёд на 5 секунд | +5 с / → |
| Повтор текущей фразы | ↺ Реплика |
| Переход к реплике | Нажатие на неё в боковой панели |
| Скорость воспроизведения | Список 0.75×–1.5× |
| Корректировка синхронизации | «Сдвиг субтитров, с» |

Положительный сдвиг показывает субтитры позже, отрицательный — раньше. По умолчанию используйте **0 секунд**. Сдвиг применяется к обоим языкам.

## Ограничения текущей версии

- Нужны готовые субтитры. Автоматическое распознавание речи и перевод пока не реализованы.
- Загрузка видео с YouTube и торрентов не встроена: приложение открывает уже скачанные файлы.
- Субтитры в виде изображений не распознаются.
- Встроенные субтитры без языковых меток нужно извлечь отдельно и подключить вручную.
- Русские реплики привязываются к английским по максимальному пересечению времени, а не по смыслу. Разное разбиение диалогов может давать неточное соответствие.
- Общий временной сдвиг не исправляет различия между монтажными версиями фильма или постепенно нарастающую рассинхронизацию.
- Поддержка видео и аудио зависит от установленных модулей GStreamer.

## Данные и приватность

История хранится в `~/.local/state/lingua-cinema/history.json`. Если задана переменная `XDG_STATE_HOME`, используется каталог `lingua-cinema` внутри неё.

В истории сохраняются локальные пути к фильмам и субтитрам, позиция просмотра и сдвиг. Само приложение ничего не отправляет во внешние сервисы.

## Для разработчиков

**Стек:** Python 3, PyGObject, GTK 3, GStreamer, FFmpeg / ffprobe.

```text
app.py                  Окно приложения и воспроизведение
subtitles.py            Разбор и сопоставление субтитров
start.sh                Запуск из папки проекта
README.md               Описание и инструкция
docs/images/           Скриншот приложения
tests/                 Тесты обработки субтитров
```

Запуск тестов:

```bash
python3 -m unittest discover -s tests -v
```

Тесты проверяют чтение SRT/VTT, очистку разметки, отбрасывание некорректных интервалов и сопоставление реплик по времени.
